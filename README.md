# Spirit-Chaos-maki
Spirit Chaos is a browser-based 2D adventure game built with Phaser 3. You play as Lia, who comes home to find three spirits — Poppy, Citrus, and Melody — have taken over her house. To restore order, you must explore different rooms, interact with increasingly unhinged objects and characters, and collect three lost music notes.

 How to Play / Install

**Option 1: Play Online (Recommended)**
You can play the game directly in your browser without downloading anything!
👉 https://timely-bublanina-cc0bdd.netlify.app

**Option 2: Run Locally (For Developers)**
To download and run the game on your own machine:
1. Ensure you have [Node.js](https://nodejs.org/) installed.
2. Clone this repository or download the ZIP file.
3. Open a terminal in the project folder and install dependencies:
   ```bash
   npm install
   ```
4. Start the local development server:
   ```bash
   npm run dev
   ```
5. Open your browser and go to `http://localhost:5173` (or the port shown in your terminal).


or 

Open your terminal and run npm run build.
This will create a dist folder containing the finished, compressed game.
